Prepare for questions

The brief says no paid subscriptions are provided. Does it run without OpenAI?
Not today. The runtime model, guardian and embeddings use OpenAI, and semantic action review uses Jev. The gateway is OpenAI-compatible, so a local backend is the natural next step, but it is not built. The deterministic layer and npm test work without network access.
What is the latency overhead?
Per stage, p95: topic detection 683 ms, guardian 2316 ms, Jev 750 ms. The guardian runs only for sessions with a topic candidate. End-to-end agent latency was not measured.
What if the LLM is wrong?
Deterministic rules run first and a model cannot override a hard prohibition. A model accusation without a verifiable quote is held for admin review, not auto-confirmed. Earlier misses are kept in the reports.
Can the agent bypass Blackwall?
Through the managed plugin or the gateway, no. A user with control of the host can disable the plugin, and there is no OS sandbox. A production deployment needs a managed executor.
Can judges change the config live?
Yes. Publish rules, thresholds, topic catalog or threat feed from the Policies tab, no restart. A stale or invalid publication is rejected and the active version stays.
How do you handle known historical attacks?
A versioned threat feed matched deterministically (RE2, no backtracking): unsafe deserialization, trust_remote_code, curl | sh, reverse shells, leaks to paste services. It is published manually; automatic download is not built.
MCP and agent-to-agent?
Not implemented. The gateway and plugin pattern is the same one those adapters would use.
